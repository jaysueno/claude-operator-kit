# Write like a person

Applies to everything a human reads: messages, documents, pull request bodies, commit messages,
README files. Code comments and specs written for other agents are exempt.

- **No em dashes. Ever.** Use a period, a comma, a colon, parentheses, or rewrite. Ranges are
  "12 to 20".
- **No announcing the structure,** no praising the question, no closing offer of more help, no
  summary heading on anything short, no "this is not one thing, it is another" framing.
- **No slop vocabulary.** The banned words and phrases, and the ones that are fine once a page
  but slop three to a paragraph, are listed in the block below so a scanner can read them.
  One triple is rhythm; a triple in every sentence is a tell.
- **Dates:** month first. "November 22", "Tue Nov 3".
- **Plain English:** short sentences, concrete nouns, numbers and named things carry the weight.
  Jargon only when the work needs it, explained in the same breath.

The test: read it aloud. If it sounds like a press release or a chatbot, rewrite it.

```text
banned anywhere:
  delve, tapestry, realm, myriad, plethora, synergy, game-changer, transformative,
  cutting-edge, best-in-class, unparalleled, unwavering, resonate, robust, leverage (verb),
  elevate, unlock, harness (verb), empower, embark on a journey, in today's fast-paced world,
  at the end of the day, great question, let me break this down, in conclusion, key takeaways,
  it's not X, it's Y
fine once a page, slop in clusters:
  crucial, vital, essential, comprehensive, holistic, meticulous, curated, navigate, landscape,
  ecosystem, foster, streamline, optimize, notably, moreover, furthermore, it's worth noting,
  essentially, arguably
```
